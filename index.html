Build your own AI agent in one hour

By the end of this page you will have an AI assistant running on your own computer, with a personality you wrote and a tool you built. It uses the GitHub Copilot account you already have. No API keys. Nothing to pay for.

The hour
  1. Install it (10 minutes)
  2. Talk to it (10 minutes)
  3. Give it a personality (10 minutes)
  4. Build your first agent (15 minutes)
  5. Use it from anywhere (10 minutes)
  6. Share it (5 minutes)

You need: a Mac, Windows or Linux computer, a GitHub account with Copilot (the free plan works), and a terminal. If you have never opened a terminal, that's fine. Every command on this page is copy and paste.

What you're building: a Brainstem. It's a small server that sits on your computer, thinks with GitHub Copilot, and can run little programs you write, called agents. Think of it as the brain, and each agent as one skill it can use.

0:00
1. Install it

Open a terminal and paste one line.

Mac or Linux

curl -fsSL https://kody-w.github.io/rapp-installer/install.sh | bash

Windows (PowerShell)

irm https://raw.githubusercontent.com/kody-w/rapp-installer/main/install.ps1 | iex

The installer fetches Python, Git and the GitHub tool if your machine is missing them. Then sign in once and start it:

gh auth login
brainstem

A browser tab opens at http://localhost:7071. That page is your Brainstem. If the tab doesn't open on its own, open that address yourself.

Check: you see a chat box in your browser. Type "hello" and get a reply.
If sign-in gets in the way

If gh auth login isn't available, just run brainstem. The web page walks you through signing in with a code on github.com.

0:10
2. Talk to it

You've talked to it in the browser. Now talk to it from the terminal, because that's how every other program will talk to it too. Open a second terminal window and leave the first one running.

First, ask if it's alive:

curl http://localhost:7071/health

You get back a list of the agents it knows. Now send it a message:

curl http://localhost:7071/chat \
  -H "Content-Type: application/json" \
  -d '{"user_input": "What can you do?"}'

The answer comes back in a field called response. That's the whole interface. Anything that can send a web request can use your Brainstem: a shortcut on your phone, a spreadsheet, another program, another Brainstem.

Check: you see "response": "..." in the terminal.

The Brainstem doesn't remember conversations between requests. If you want it to remember, send the earlier messages back in conversation_history. Keeping the memory on your side is what makes it simple and safe.

0:20
3. Give it a personality

The Brainstem's personality lives in one plain-text file called soul.md. Find it here:

~/.brainstem/src/rapp_brainstem/soul.md

Open it in any text editor (TextEdit and Notepad are fine). Read what's there. Then add a few lines of your own at the bottom, in plain English. For example:

You help me plan meals for a family of four.
Keep answers short. Suggest one thing at a time.
Never suggest fish; nobody here eats it.

Save the file. Go back to the browser and ask it something. It reads soul.md fresh on every message, so there's nothing to restart.

Check: the Brainstem now answers the way you told it to.

This is the most important idea on the page. Your assistant is a folder of plain files you can read. The personality is a text file. The skills, which come next, are small files too. Nothing is hidden from you.

0:30
4. Build your first agent

An agent is one Python file that teaches the Brainstem one thing it can do. You don't need to know Python to do this step. Copy the file, change the words, done.

Agents live in this folder:

~/.brainstem/src/rapp_brainstem/agents/

Create a new file there called dice_agent.py. The name must end in _agent.py; that's how the Brainstem finds it. Paste this in:

import random
from basic_agent import BasicAgent

class DiceAgent(BasicAgent):
    def __init__(self):
        self.name = "RollDice"
        self.metadata = {
            "name": self.name,
            "description": "Rolls dice. Use this whenever someone asks to roll, flip, or pick at random.",
            "parameters": {
                "type": "object",
                "properties": {
                    "sides": {"type": "integer", "description": "How many sides the die has. Default 6."},
                    "count": {"type": "integer", "description": "How many dice to roll. Default 1."}
                },
                "required": []
            }
        }
        super().__init__()

    def perform(self, sides=6, count=1, **kwargs):
        rolls = [random.randint(1, int(sides)) for _ in range(int(count))]
        return f"Rolled {count} d{sides}: {rolls} (total {sum(rolls)})"

Save it. Now ask the Brainstem, in the browser or with curl: "Roll three six-sided dice."

Check: the answer includes real numbers from your code, and the reply mentions it used RollDice.

What just happened: the Brainstem noticed your new file, read the description to learn when to use it, and called your perform function when the question fit. There's no registration step and no restart. The description is the part that matters most. Write it the way you'd explain the tool to a new coworker.

Now make one that's yours. Copy dice_agent.py to a new name and change three things: the name, the description, and what perform returns. Ideas that take five minutes:

  • An agent that returns your family's standing weekly schedule.
  • An agent that reads a text file of your notes and hands it to the Brainstem.
  • An agent that calls a public weather or news website and returns the result.
Check: curl http://localhost:7071/health lists your new agent by name.

0:45
5. Use it from anywhere

Because the whole interface is one web address, you can plug your Brainstem into things you already use.

From a script. Any language that can make a web request. Here's Python:

import requests
r = requests.post("http://localhost:7071/chat",
                  json={"user_input": "Roll two dice"})
print(r.json()["response"])

From your phone or another computer on your Wi-Fi. Replace localhost with your computer's address on the network, like http://192.168.1.20:7071. An iPhone Shortcut with a "Get contents of URL" step can send user_input and read response.

From Claude Code or Copilot CLI. Both can install the Brainstem as a plugin and talk to it directly:

claude plugin marketplace add kody-w/rapp-installer
claude plugin install rapp@brainstem
Check: you got a response back from somewhere that is not the browser tab.

The promise behind all of this: POST /chat in, response out, agents as *_agent.py files. That contract doesn't change between versions. Build on it and your work keeps working.

0:55
6. Share it

Your agents are just files, so sharing them is just sharing files.

Give a friend your agents. Put your agents/ folder in a GitHub repository. In their Brainstem's web page there's a Sources panel. They paste your repo's address, and your agents load into their Brainstem. Any Python packages your agents need get installed on the way.

Publish one for everyone. The public registry of agents is RAR. Open a pull request with your agent file, and it becomes something anyone can pull.

Check: someone other than you has run one of your agents.

1:00
You're done. What you have now.

An assistant that runs on your own machine, with a personality you wrote, skills you built, and a door that anything can knock on. It costs nothing beyond your GitHub account, and every part of it is a plain file you can read, copy, and hand to someone else.
